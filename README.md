# Benítez Ingeniería

Sitio web one-page mejorado para Benítez Ingeniería.

## Qué incluye

- `index.html`: Página única con secciones de inicio, filosofía/trayectoria, servicios y contacto.
- `styles.css`: Diseño moderno, responsive y con navegación móvil.
- `script.js`: Validación del formulario y menú móvil.
- `logo.jpeg`: Logo de la empresa para el encabezado.

## Características principales

- Diseño limpio de alto impacto visual.
- Navegación fija y responsive.
- Botón flotante permanente de WhatsApp.
- Sección de galería para mostrar trabajos realizados.
- Formulario de contacto con correo y teléfono.

## Cómo usar

1. Abre `index.html` en tu navegador.
2. Reemplaza los textos, enlaces y fotos de galería con tus contenidos reales.
3. Si deseas, convierte esta página en WordPress con Elementor para una administración completa.

## Notas

- La página actual es un prototipo estático. Si luego quieres, puedo ayudarte a migrarla a WordPress/Elementor para que puedas autoadministrar el contenido fácilmente.
